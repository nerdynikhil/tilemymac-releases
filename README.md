# TileMyMac releases

Downloads and release notes for [TileMyMac](https://tilemymac.app), the calmer way to arrange windows on your Mac.

- **Download the latest version:** [TileMyMac.dmg](https://github.com/nerdynikhil/tilemymac-releases/releases/latest/download/TileMyMac.dmg)
- **What's new in each version:** [tilemymac.app/updates](https://tilemymac.app/updates)
- **Requires:** macOS 13 Ventura or later

This repository only holds release builds and notes. The app's source code is not published here.

## Installing or updating

1. Quit TileMyMac if it's running.
2. Open the downloaded DMG and drag TileMyMac to Applications. Choose **Replace** if asked.
3. TileMyMac isn't notarized by Apple yet. If macOS warns you the first time you open it, go to **System Settings › Privacy & Security** and click **Open Anyway**.

Your license stays activated when you update.
